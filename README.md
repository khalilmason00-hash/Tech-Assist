# TechAssist

## Interactive IT Troubleshooting Assistant

TechAssist is a web-based troubleshooting tool designed to help users diagnose and resolve common technical issues through guided step-by-step solutions.

## Features

- Interactive troubleshooting workflows
- Internet connectivity troubleshooting
- VPN troubleshooting
- Printer troubleshooting
- Outlook/email troubleshooting
- Audio troubleshooting
- Slow computer troubleshooting
- Progress tracking
- Troubleshooting history
- Solution summary generation
- Reset/restart functionality

## Purpose

Built as a portfolio project to demonstrate practical IT support skills, troubleshooting methodology, and front-end development abilities.

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Vite

## Project Highlights

- Designed user-friendly troubleshooting flows similar to real IT Service Desk procedures
- Created structured problem-solving paths for common end-user issues
- Applied IT support concepts including diagnosis, escalation thinking, and resolution documentation
